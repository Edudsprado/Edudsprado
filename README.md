## 🌐 Atuação na StudioCriandoWeb

Essa prática vem ampliando meus conhecimentos em:

- Componentização de interfaces com **React e TypeScript**.
- Estilização e adaptação de layouts com **Tailwind CSS**.
- Organização de páginas e navegação com **TanStack Start e TanStack Router**.
- Desenvolvimento e build com **Vite**, além do uso de **Git e GitHub** para versionamento e colaboração.
- Publicação de demonstrações do portfólio no **Cloudflare Pages**.

A stack do site institucional inclui **React 19, TypeScript, TanStack Start/Router e Tailwind CSS 4**. Minha experiência com essas tecnologias está em desenvolvimento e é construída na prática dos projetos.

## 🚀 Projetos em destaque

### ✈️ [Elite — Aviação Executiva](https://github.com/Edudsprado/Elite)

Landing page demonstrativa para o portfólio da StudioCriandoWeb, com apresentação de aeronaves, vídeo de abertura e interface de cotação.

**Tecnologias:** React · TypeScript · Vite · Tailwind CSS · Cloudflare Pages.

**Escopo:** MVP de portfólio. A cotação é simulada no navegador e não envia pedidos nem realiza reservas.

[Ver demonstração](https://elite-studiocriandoweb.pages.dev/)

### 🐾 [P3TS — Pet Store](https://github.com/Edudsprado/P3TS)

Interface demonstrativa de petshop para o portfólio da StudioCriandoWeb, com catálogo, filtros, carrinho em memória e formulário de agendamento.

**Tecnologias:** React · TypeScript · Vite · Tailwind CSS · Cloudflare Pages.

**Escopo:** demonstração de interface. Compra, agendamento e newsletter são simulados; não há processamento de pagamentos, envio de pedidos ou persistência de dados.

[Ver demonstração](https://p3ts-studiocriandoweb.pages.dev/)
